# Decisions

주요 의사결정을 날짜별로 기록한다. 아래 내용은 초기 방향이며 구현 완료를 의미하지 않는다.

## 2026-10-01 — 초기 프로젝트 방향

### 프로젝트 범위

- QA 연습에 필요한 기능만 구현한다.
- production-grade 이커머스 구축은 목적에 포함하지 않는다.
- 이번 작업은 문서 초기 세팅까지 진행한다.

### 실제 PG 미사용

- 실제 결제 연동은 하지 않는다.
- 테스트 가능한 결제 성공/실패 시뮬레이션을 구현할 예정이다.
- 이유: 결제 인프라 구축은 프로젝트 핵심 목표가 아니다.

### SQLite 사용 예정

- DB로 SQLite를 사용할 예정이다.
- 이유: 별도 DB 서버 구축 비용 없이 SQL과 데이터 검증을 연습할 수 있다.

### UI 범위

- 포트폴리오 캡처가 가능한 수준의 깔끔한 UI까지만 구현한다.
- 복잡한 애니메이션이나 디자인 시스템 구축은 범위에서 제외한다.

미확정 비즈니스 정책은 [Requirements의 Open Question](requirements.md#open-question)에서 관리하며, 결정 후 관련 문서에 반영한다.
